# Abdulmajeedpharma — Admin Dashboard (Next.js)

Administrative website for the APH pharmaceutical platform.

## Stack

- Next.js 14 (App Router)
- React 18
- TypeScript
- Tailwind CSS

## Structure

```
admin/

```

```bash
cd admin
npm install

```
